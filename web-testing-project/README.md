# Manual Testing Project

## Overview

**Sauce Demo**  
URL: https://www.saucedemo.com  
Type: E-commerce web application (demo)  
Purpose: Functional web testing practice


---

## Repository Structure

| Folder | Contents |
|---|---|
| `test-plans/` | Test plan covering scope, strategy, and environment |
| `test-cases/` | Step-by-step test cases with expected results |
| `bug-reports/` | Defect reports with full attributes and lifecycle status |
| `test-report/` | Final test execution summary |
| `screenshots/` | Evidence captured during test execution |


---

- Google Chrome
- Chrome DevTools
- Snipping Tool
